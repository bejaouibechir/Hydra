Lesson 5 of 12 · Add a source

Drop your first source on the canvas

Create the cumulative job tab, place the CSV source from the registry, and distinguish placement from configuration.

Sourcesabout 10 minutespalette understood

1. Objective

Goal

Use the job-tab plus control to create the first job, rename it first-job, and drag CSV from Sources onto the empty job canvas. Do not claim the source is ready until its required file path is saved.

Why this matters

Adding a node only chooses its type and position. The registry marks CSV as a source with no input capacity, while isNodeConfigured requires a non-empty path, table, query, collection, URL, or URI before the source is configured.

Course project

Keep one cumulative Studio project named studio-course, one manual workflow named guided-workflow, and one job named first-job. Each lesson builds on the state saved by the previous one.

Prerequisites

  • Hydra API started with hdrctl serve.
  • Studio started from Hydra/studio with npm run dev.
  • The preceding lesson completed before continuing.

Evidence rule

Record the visible label, selected scene, saved file, and stable state that each gesture proves. Counts tied to your workspace and run durations can change, so do not use them as fixed thresholds. When Studio writes YAML, compare the generated key with the field you edited; when it runs work, compare the node state with the Runs detail. This keeps the canvas, the DSL, and the engine tied to the same observable project instead of treating a green screen as sufficient evidence. Before continuing, reopen the saved node or panel and reproduce the observation from a neutral selection. Keep the project path, workflow name, job tab, active scene, and relevant field beside your note so another operator can repeat the same check. If a file is generated, inspect it on disk as well as in Studio. If a run is involved, wait for a terminal state and use the Runs page instead of relying on a transient animation. These habits reveal autosave, workspace, and scene mistakes early, while the project is still small enough to correct without obscuring the cause.
