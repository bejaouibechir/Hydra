## 🟦 Couche DSL (Déclaratif)

### 📄 **sources.yaml**

```
Définit OÙ lire les données
- Type de source (csv, mysql, etc.)
- Paramètres de connexion
- Requête/table à extraire
- Taille des batches
```

### 📄 **destinations.yaml**

```
Définit OÙ écrire les données
- Type de destination (csv, mysql, etc.)
- Paramètres de connexion
- Table cible
- Mode d'écriture (append/replace)
```

### 📄 **transformations.yaml**

```
Définit COMMENT transformer les données
- Séquence d'opérations (steps)
- 5 opérations MVP : select, filter, calculate, rename, cast
- Expressions déclaratives
```

### 📄 **pipeline.yaml**

```
Définit LE FLUX du job
- Source : from (quelle source)
- Destination : to (quelle destination)
- Orchestration simple
```

## 🟩 Couche PARSERS (Validation)

### 🔍 **SourceParser**

```
Valide sources.yaml avec Pydantic
- Vérifie structure YAML
- Normalise les valeurs (batch_size défaut)
- Détecte erreurs de config
✅ Retourne : SourcesConfig (objet Python typé)
```

### 🔍 **DestinationParser**

```
Valide destinations.yaml avec Pydantic
- Vérifie structure YAML
- Normalise mode (append/replace)
- Valide paramètres obligatoires
✅ Retourne : DestinationsConfig
```

### 🔍 **TransformParser**

```
Valide transformations.yaml avec Pydantic
- Vérifie chaque step (1 op par step)
- Valide params de chaque opération
- Déduplique colonnes (select)
✅ Retourne : TransformConfig
```

---

## 🟨 Couche CORE (Logique métier)

### ⚙️ **PandasEngine**

```
Moteur d'exécution des transformations
- Reçoit DataFrame + liste de steps
- Applique chaque transformation séquentiellement
- Support 5 opérations MVP
- Pas de logique cachée (fail-fast)
✅ Input: DataFrame → Output: DataFrame transformé
```

### 🎯 **JobExecutor**

```
Orchestrateur du pipeline ETL
- Charge les 4 YAML (sources, destinations, transformations, pipeline)
- Instancie connecteurs source/destination
- Streaming batch-par-batch (pas de RAM overflow)
- Appelle PandasEngine pour chaque batch
- Mode fail-fast : 1ère erreur = stop
✅ Retourne : JobResult (success, rows_in, rows_out, duration, error)
```

---

## 🟪 Couche I/O (Connecteurs)

### 🔌 **Connector (Interface)**

```
Contrat pour tous les connecteurs
- extract_batches() : générateur de batches
- load_batches() : écriture par batches
- Support modes append/replace
📝 Implémenté par : CSVConnector, MySQLConnector (futur)
```

### 📁 **CSVConnector**

```
Connecteur pour fichiers CSV (MVP)
- Lecture streaming (yield batches)
- Écriture par chunks (pas de buffer complet)
- Gestion header automatique
- Support encodage UTF-8
✅ Production-ready pour volumes moyens (<10M lignes)
```

## 🟧 Couche SUPPORT (Utilitaires)

### 🔐 **ConfigLoader**

```
Gestion variables d'environnement
- Charge .env root (projet)
- Charge .env job (surcharge)
- Hiérarchie : job > root > OS
✅ Injection dans os.environ
```

### 🔑 **SecretResolver**

```
Résolution de variables dynamiques
- ${ENV:VAR_NAME} : variables d'environnement
- ${SECRET:path.to.secret} : secrets externes (futur)
- Traverse récursivement les dicts/lists
✅ Appliqué après parsing YAML
```

## 📦 Types publics (API stable)

### 📊 **JobResult**

```
Résultat d'exécution d'un job
- success: bool (True/False)
- rows_in: int (lignes extraites)
- rows_out: int (lignes chargées)
- duration: float (secondes)
- error: Optional[str] (message si échec)
✅ API publique garantie rétro-compatible
```

## 🔄 Flux d'exécution complet

```
┌──────────────┐
│  hydra run   │  ← Étape 6 (À venir)
└──────┬───────┘
       │
┌──────▼───────┐
│ JobExecutor  │  ← Étape 5 ✅
└──────┬───────┘
       │
       ├─→ 1. Charge YAML (sources, destinations, transformations, pipeline)
       │   ├─→ ConfigLoader (.env)
       │   ├─→ SecretResolver (${ENV:...})
       │   └─→ Parsers (validation Pydantic)
       │
       ├─→ 2. Instancie connecteurs
       │   └─→ CSVConnector (source + destination)
       │
       ├─→ 3. STREAMING batch-par-batch
       │   │
       │   ├─→ CSVConnector.extract_batches()
       │   │   └─→ yield [ligne1, ligne2, ...] (dict)
       │   │
       │   ├─→ PandasEngine.apply_pipeline()
       │   │   ├─→ DataFrame(batch)
       │   │   ├─→ apply step 1 (select)
       │   │   ├─→ apply step 2 (filter)
       │   │   ├─→ apply step N (...)
       │   │   └─→ return DataFrame transformé
       │   │
       │   └─→ CSVConnector.load_batches()
       │       └─→ write CSV (append/replace)
       │
       └─→ 4. Retourne JobResult
           └─→ success + métriques
```
