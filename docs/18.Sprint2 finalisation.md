## 🐛 3. DÉFIS RENCONTRÉS ET SOLUTIONS

### Défi 1 : Ports Docker non exposés

**Symptôme** :

```
Connection refused on localhost:5432
```

**Cause** : Containers créés sans mapping de ports

```bash
docker ps
postgres1   5432/tcp    # ❌ Pas de 0.0.0.0:5432->5432
```

**Solution** :

```bash
docker rm postgres1 postgres2
docker run -d --name postgres1 -p 5432:5432 -e POSTGRES_PASSWORD=postgres postgres:15
docker run -d --name postgres2 -p 5431:5432 -e POSTGRES_PASSWORD=postgres postgres:15
```

**Temps perdu** : 30min  
**Leçon** : Toujours vérifier les ports exposés avec `docker ps`

---

### Défi 2 : Parsing constraint_cols depuis PostgreSQL

**Symptôme** :

```python
ValueError: key=['id'] ne correspond à aucune contrainte unique.
Contraintes disponibles:
  - e2e_employees_pkey: {id}  # ← Format string, pas liste !
```

**Cause** : PostgreSQL retourne les arrays dans différents formats :

- Liste Python : `['id']` (attendu)
- String array : `"{id}"` ou `"{region,product_id}"` (reçu)

**Solution** :

```python
# Parse tous les formats possibles
if isinstance(constraint_cols, list):
    constraint_cols_list = constraint_cols
elif isinstance(constraint_cols, str):
    # "{id}" ou "{region,product_id}"
    constraint_cols_list = constraint_cols.strip('{}').split(',')
else:
    constraint_cols_list = list(constraint_cols)

constraint_cols_list = [col.strip() for col in constraint_cols_list]
```

**Temps perdu** : 1h  
**Leçon** : Tester avec données réelles, pas seulement mocks

---

### Défi 3 : LIKE avec % dans psycopg2

**Symptôme** :

```python
query = "SELECT * FROM users WHERE name LIKE '%Active%'"
# IndexError: tuple index out of range
```

**Cause** : psycopg2 interprète `%` comme placeholder quand on passe `params=()`

**Solution** :

```python
# AVANT (bug)
cursor.execute(query, params or ())

# APRÈS (corrigé)
if params:
    cursor.execute(query, params)
else:
    cursor.execute(query)  # Sans tuple vide
```

**Temps perdu** : 45min  
**Leçon** : Attention aux différences subtiles entre drivers SQL

---

### Défi 4 : Méthode abstraite manquante

**Symptôme** :

```python
TypeError: Can't instantiate abstract class PostgreSQLConnector 
without an implementation for abstract method '_build_columns_query'
```

**Cause** : `BaseDBConnector` exige cette méthode (oubliée dans première version)

**Solution** :

```python
def _build_columns_query(self, table: str) -> str:
    """Requête d'inspection des colonnes."""
    schema, table_name = self._parse_table(table)
    return f'SELECT * FROM {self._quote_identifier(schema, table_name)} LIMIT 0'
```

**Temps perdu** : 15min  
**Leçon** : Vérifier toutes les méthodes abstraites de la classe parent
