JSON Connector - Sprint 4

Connecteur unique pour JSON/JSONL avec intelligence nested.

def extract_batches(
    self,
    *,
    file: Optional[str] = None,
    url: Optional[str] = None,
    batch_size: int = 10_000,
    flatten_depth: int = 1,
    json_path: Optional[str] = None,
) -> Iterator[Batch]:
    """
    Extrait batches depuis JSON/JSONL.

    Args:
        file: Chemin fichier local (requis Sprint 4)
        url: URL distante (Sprint 5+, non implémenté)
        batch_size: Taille des batches (défaut 10000)
        flatten_depth: Profondeur auto-flatten (0-3)
            - 0: Pas de flatten (garde nested)
            - 1: Flatten 1 niveau (défaut)
            - 2: Flatten 2 niveaux
            - 3: Flatten 3 niveaux (max)
        json_path: JSONPath extraction (Sprint 5+)

    Yields:
        Batch: Liste de dict

    Raises:
        ValueError: Paramètres invalides
        FileNotFoundError: Fichier introuvable
        JSONDecodeError: JSON invalide

    Examples:
        >>> # Extraction simple
        >>> for batch in conn.extract_batches(file="data.json"):
        ...     process(batch)

        >>> # Avec flatten custom
        >>> for batch in conn.extract_batches(file="nested.json", flatten_depth=2):
        ...     process(batch)
    """
    # Validation paramètres
    if not file and not url:
        raise ValueError(
            f"{self.__class__.__name__} [{self.name}]: "
            f"'file' ou 'url' requis."
        )

    if file and url:
        raise ValueError(
            f"{self.__class__.__name__} [{self.name}]: "
            f"'file' et 'url' mutuellement exclusifs."
        )

    if url:
        raise NotImplementedError(
            f"{self.__class__.__name__} [{self.name}]: "
            f"URL extraction disponible Sprint 5+."
        )

    if not isinstance(flatten_depth, int) or not 0 <= flatten_depth <= 3:
        raise ValueError(
            f"{self.__class__.__name__} [{self.name}]: "
            f"'flatten_depth' doit être 0-3, reçu: {flatten_depth}"
        )

    if not isinstance(batch_size, int) or batch_size < 1:
        raise ValueError(
            f"{self.__class__.__name__} [{self.name}]: "
            f"'batch_size' doit être >= 1, reçu: {batch_size}"
        )

    # Extraction
    yield from self._extract_from_file(
        file=file,
        batch_size=batch_size,
        flatten_depth=flatten_depth,
    )
```

def _extract_from_file(
    self,
    *,
    file: str,
    batch_size: int,
    flatten_depth: int,
) -> Iterator[Batch]:
    """
    Extraction depuis fichier local.

    Détection automatique du format:
    - .json → JSON standard (object ou array)
    - .jsonl, .ndjson → JSON Lines

    Args:
        file: Chemin fichier
        batch_size: Taille batches
        flatten_depth: Profondeur flatten

    Yields:
        Batch

    Raises:
        FileNotFoundError: Fichier introuvable
    """
    file_path = Path(file)

    if not file_path.exists():
        raise FileNotFoundError(
            f"{self.__class__.__name__} [{self.name}]: "
            f"Fichier introuvable: {file}"
        )

    if not file_path.is_file():
        raise ValueError(
            f"{self.__class__.__name__} [{self.name}]: "
            f"Chemin n'est pas un fichier: {file}"
        )

    # Détection format par extension
    suffix = file_path.suffix.lower()

    if suffix in [".jsonl", ".ndjson"]:
        yield from self._extract_jsonl(file_path, batch_size, flatten_depth)
    elif suffix in [".json"]:
        yield from self._extract_json(file_path, batch_size, flatten_depth)
    else:
        # Défaut: tenter JSON standard
        warnings.warn(
            f"{self.__class__.__name__} [{self.name}]: "
            f"Extension inconnue '{suffix}', tentative JSON standard."
        )
        yield from self._extract_json(file_path, batch_size, flatten_depth)
```

**Défis identifiés** :

1. ⚠️ **Détection format** : Basé sur extension (simple mais limité)
2. ⚠️ **Extension inconnue** : Warning + fallback JSON
3. ⚠️ **Path validation** : Exists + is_file

**Stratégie retenue** :

- Extension-based (simple, rapide)
- Fallback graceful avec warning
- Sprint 5+ : Content-based detection

def _extract_json(
    self,
    file_path: Path,
    batch_size: int,
    flatten_depth: int,
) -> Iterator[Batch]:
    """
    Extraction JSON standard.

    Formats supportés:
    - Objet unique: {"key": "value"}
    - Array d'objets: [{"id": 1}, {"id": 2}]

    Args:
        file_path: Path objet
        batch_size: Taille batches
        flatten_depth: Profondeur flatten

    Yields:
        Batch

    Raises:
        JSONDecodeError: JSON invalide
    """
    # Lecture fichier
    try:
        with open(file_path, 'r', encoding='utf-8') as f:
            data = json.load(f)
    except json.JSONDecodeError as e:
        raise ValueError(
            f"{self.__class__.__name__} [{self.name}]: "
            f"JSON invalide dans '{file_path.name}'.\n"
            f"  Ligne {e.lineno}, colonne {e.colno}: {e.msg}"
        ) from e
    except UnicodeDecodeError as e:
        raise ValueError(
            f"{self.__class__.__name__} [{self.name}]: "
            f"Encodage invalide dans '{file_path.name}'. "
            f"Utilisez UTF-8."
        ) from e
    except Exception as e:
        raise ValueError(
            f"{self.__class__.__name__} [{self.name}]: "
            f"Erreur lecture '{file_path.name}': {e}"
        ) from e

    # Normaliser en liste de records
    if isinstance(data, dict):
        # Objet unique → liste de 1 élément
        records = [data]
    elif isinstance(data, list):
        # Array → déjà liste
        if not data:
            # Liste vide → return empty
            return
        records = data
    else:
        raise ValueError(
            f"{self.__class__.__name__} [{self.name}]: "
            f"Format JSON non supporté. "
            f"Attendu: dict ou list, reçu: {type(data).__name__}"
        )

    # Flatten si demandé
    if flatten_depth > 0:
        records = self._flatten_records(records, flatten_depth)

    # Yield par batches
    for i in range(0, len(records), batch_size):
        batch = records[i:i + batch_size]
        yield batch
```

**Défis identifiés** :

1. ⚠️ **Gestion erreurs JSON** : Messages actionnables (ligne/colonne)
2. ⚠️ **Encodage** : UTF-8 strict, erreur claire si échec
3. ⚠️ **Format detection** : dict vs list, rejet si autre

**Stratégies** :

- ✅ Messages d'erreur détaillés (ligne/col pour JSONDecodeError)
- ✅ Normalisation dict → list (1 élément)
- ✅ Liste vide → return early (pas d'erreur)

def _extract_jsonl(
    self,
    file_path: Path,
    batch_size: int,
    flatten_depth: int,
) -> Iterator[Batch]:
    """
    Extraction JSONL (JSON Lines).

    Format: 1 objet JSON par ligne.

    Args:
        file_path: Path objet
        batch_size: Taille batches
        flatten_depth: Profondeur flatten

    Yields:
        Batch

    Raises:
        ValueError: JSON invalide sur une ligne
    """
    batch = []

    try:
        with open(file_path, 'r', encoding='utf-8') as f:
            for line_num, line in enumerate(f, start=1):
                line = line.strip()

                # Ignorer lignes vides
                if not line:
                    continue

                # Parse JSON
                try:
                    record = json.loads(line)
                except json.JSONDecodeError as e:
                    raise ValueError(
                        f"{self.__class__.__name__} [{self.name}]: "
                        f"JSON invalide dans '{file_path.name}' ligne {line_num}.\n"
                        f"  Erreur: {e.msg}"
                    ) from e

                batch.append(record)

                # Yield batch si plein
                if len(batch) >= batch_size:
                    if flatten_depth > 0:
                        batch = self._flatten_records(batch, flatten_depth)
                    yield batch
                    batch = []

            # Yield dernier batch
            if batch:
                if flatten_depth > 0:
                    batch = self._flatten_records(batch, flatten_depth)
                yield batch

    except UnicodeDecodeError as e:
        raise ValueError(
            f"{self.__class__.__name__} [{self.name}]: "
            f"Encodage invalide dans '{file_path.name}'. "
            f"Utilisez UTF-8."
        ) from e
    except Exception as e:
        if not isinstance(e, ValueError):
            raise ValueError(
                f"{self.__class__.__name__} [{self.name}]: "
                f"Erreur lecture '{file_path.name}': {e}"
            ) from e
        raise
```

**Défis identifiés** :

1. ⚠️ **Streaming** : Ne pas charger tout en mémoire
2. ⚠️ **Erreur ligne** : Identifier quelle ligne est invalide
3. ⚠️ **Lignes vides** : Ignorer (skip, pas erreur)

**Stratégies** :

- ✅ Lecture ligne par ligne (streaming)
- ✅ Batch accumulation + yield périodique
- ✅ Numéro de ligne dans erreurs

```python
def _flatten_records(
    self,
    records: List[Dict[str, Any]],
    flatten_depth: int,
) -> List[Dict[str, Any]]:
    """
    Flatten nested JSON avec pandas json_normalize.

    Utilise pandas.json_normalize qui gère:
    - Nested objects (user.name → user.name)
    - Max depth control
    - Missing keys → NaN

    Args:
        records: Liste de dict (JSON objects)
        flatten_depth: Profondeur (1-3)

    Returns:
        Liste de dict flatten

    Notes:
        - Si flatten échoue → warning + return original
        - NaN pandas → None en output
    """
    if not records:
        return records

    try:
        # Pandas json_normalize
        df = json_normalize(records, max_level=flatten_depth)

        # Convertir NaN → None
        df = df.where(pd.notna(df), None)

        # Convertir back to list of dict
        return df.to_dict('records')

    except Exception as e:
        # Flatten échoué → warning + return original
        warnings.warn(
            f"{self.__class__.__name__} [{self.name}]: "
            f"Flatten échoué (depth={flatten_depth}). "
            f"Données retournées non-flatten.\n"
            f"  Erreur: {type(e).__name__}: {e}",
            RuntimeWarning
        )
        return records
```

**Défis identifiés** :

1. ⚠️ **Flatten failure** : Ne pas crasher le job entier
2. ⚠️ **NaN handling** : pandas NaN → Python None
3. ⚠️ **Empty records** : Early return

**Stratégies** :

- ✅ Try-except avec warning (graceful degradation)
- ✅ NaN → None conversion
- ✅ Return original si échec (user peut débugger)

### Défi 1 : Détection automatique format JSON vs JSONL

**Problème** :
Comment détecter automatiquement si un fichier est JSON standard ou JSONL sans charger tout en mémoire ?

**Options évaluées** :
1. ❌ **Content-based** : Lire première ligne et tester
   - Pro : Robuste
   - Con : I/O supplémentaire, complexité

2. ✅ **Extension-based** : Basé sur `.json` vs `.jsonl`
   - Pro : Simple, rapide, standard industrie
   - Con : Utilisateur peut mal nommer fichier

**Solution retenue** :
```python
if suffix in [".jsonl", ".ndjson"]:
    yield from self._extract_jsonl(...)
elif suffix in [".json"]:
    yield from self._extract_json(...)
else:
    warnings.warn(f"Extension inconnue, tentative JSON")
    yield from self._extract_json(...)
```

**Justification** :

- Extension-based est standard industrie (`.jsonl` = JSON Lines)
- Fallback graceful avec warning
- Performance optimale (pas d'I/O preview)
- Sprint 5+ : Ajouter content-based si demandé

**Impact** : Faible (30min débat, solution simple)

### Défi 2 : Flatten nested - Pandas vs Custom

**Problème** :
Comment flatten JSON nested de manière robuste et performante ?

**Options évaluées** :

1. ✅ **Pandas json_normalize** : Utiliser pandas builtin
   
   - Pro : Robuste, testé, performant, maintenu
   - Con : Dépendance pandas (déjà présente)

2. ❌ **Custom recursive** : Implémenter flatten custom
   
   - Pro : Contrôle total
   - Con : Complexité, bugs, maintenance, pas testé

3. ❌ **Bibliothèque tierce** : flatten-json, jsonflattener
   
   - Pro : Spécialisé
   - Con : Dépendance supplémentaire, moins standard

**Solution retenue** :

```python
def _flatten_records(self, records, flatten_depth):
    try:
        df = json_normalize(records, max_level=flatten_depth)
        return df.to_dict('records')
    except Exception as e:
        warnings.warn(f"Flatten échoué: {e}")
        return records  # Graceful degradation
```

**Justification** :

- Pandas json_normalize est production-ready
- Gère cas edge (missing keys, types mixtes)
- POC validé (10k records <1s)
- Graceful degradation si échec

**Impact** : Moyen (2h POC + validation)

### Défi 4 : JSONL streaming sans OOM

**Problème** :
Comment lire JSONL de plusieurs Go sans Out Of Memory ?

**Options évaluées** :

1. ❌ **Load all** : `json.loads(file.read())`
   
   - Pro : Simple
   - Con : OOM sur gros fichiers

2. ✅ **Line-by-line** : Itérer ligne par ligne
   
   - Pro : Mémoire constante
   - Con : Légèrement plus complexe

**Solution retenue** :

```python
batch = []
with open(file_path) as f:
    for line in f:
        record = json.loads(line)
        batch.append(record)

        if len(batch) >= batch_size:
            yield batch
            batch = []
```

**Justification** :

- Streaming vrai (mémoire = batch_size)
- Fonctionne sur fichiers 100+ Go
- Pattern standard JSONL

**Impact** : Faible (1h implémentation)

### Défi 5 : NaN handling (pandas → Python)

**Problème** :
Pandas remplace valeurs manquantes par `NaN`, mais Python dict attend `None`.

**Exemple** :

```python
# Pandas DataFrame
df = pd.DataFrame([{"id": 1, "name": None}])
df.to_dict('records')
# → [{"id": 1, "name": NaN}]  ← Problème !
```

**Solution retenue** :

```python
df = df.where(pd.notna(df), None)
df.to_dict('records')
# → [{"id": 1, "name": None}]  ← Correct
```

**Justification** :

- None est standard Python pour valeurs manquantes
- JSON serializable (`null`)
- Compatibilité downstream (SQL, CSV)

**Impact** : Faible (30min recherche + fix)
