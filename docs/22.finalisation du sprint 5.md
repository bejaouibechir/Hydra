## 🎯 CAS D'USAGE VALIDÉS

### **Exemple 1 : MongoDB → CSV**

```yaml
sources:
  mongodb_source:
    type: mongodb
    connection:
      uri: "mongodb://localhost:27017/"
      database: hydra_test_db
    extract:
      collection: users_flat
      batch_size: 1000

destinations:
  csv_dest:
    type: csv
    load:
      table: users_export.csv
```

✅ **Validé par** : `test_mongodb_to_csv_pipeline`
