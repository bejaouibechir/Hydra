## **Étape 8 — Connecteur MySQL/MariaDB**

**Connecteur MySQL/MariaDB (Option B ultra-minimale)**

## 1) Décisions validées

- `ConnectorInterface` : **inchangé**

- `JobExecutor` : **aucune modification** (il utilise déjà `extract_batches()` / `load_batches()`)

- Driver : **`mysql-connector-python`**

- Tests d’intégration : **via Docker**

- Stratégie : **BaseDBConnector minimal + connecteur MySQL/MariaDB complet**

---

## 2) Cible d’architecture

- **`BaseDBConnector` (≤ 80 lignes)** : uniquement le code DB réellement partagé
  
  - `__init__(connection_params)`
  
  - `_build_connection_string()` (abstrait)
  
  - `test_connection()` (template method)
  
  - `_execute_query_batches()` (helper `fetchmany()`)
  
  - `_get_table_columns()` (helper inspection)

- **`MySQLMariaDBConnector` (≤ 150 lignes)** : toute la logique spécifique MySQL/MariaDB
  
  - Construction DSN MySQL/MariaDB
  
  - `extract_batches()` via `LIMIT/OFFSET` (ou curseur + `fetchmany` selon query)
  
  - `load_batches()` : `TRUNCATE` + `INSERT` (replace) / `INSERT` (append)
  
  - Mapping types MySQL → pandas (minimum nécessaire)
  
  - Gestion d’erreurs spécifiques MySQL

---

## 3) Livrables à produire (ordre strict)

1. Créer le fichier **`internal/connector/base_db_connector.py`**

2. Créer le fichier **`internal/connector/mysql_mariadb_connector.py`**

3. Mettre à jour le fichier **`internal/connector/registry.py`**
   
   - `mysql` → `MySQLMariaDBConnector`
   
   - `mariadb` → `MySQLMariaDBConnector`

4. Mettre à jour **`requirements.txt`**
   
   - ajouter `mysql-connector-python`

5. Créer le fichier **`tests/docker/docker-compose.test.yml`**
   
   - 1 conteneur MySQL + 1 conteneur MariaDB
   
   - scripts SQL de seed (tables + données)

6. Créer le dossier **`examples/mysql_demos/`** avec 3 démos prêtes CLI
   
   - `mysql_to_csv/`
   
   - `csv_to_mysql/`
   
   - `mysql_to_mysql/`

---

## 4) Scénarios de validation obligatoires

- Démo 1 : **MySQL/MariaDB → CSV**

- Démo 2 : **CSV → MySQL/MariaDB**

- Démo 3 : **MySQL/MariaDB → MySQL/MariaDB**

- Tests : **pytest + Docker** (smoke tests + vérifs basiques rows/colonnes)

---

## 5) Règles de cadrage

- Pas de pooling/retry/optimisations avancées dans cette étape

- Pas de refactor du core

- Factorisation DB avancée reportée (quand un 2e connecteur DB existe réellement)

---

## 6) Mode de livraison

- Procéder **fichier par fichier**, dans l’ordre ci-dessus, avec test/validation à la fin de chaque bloc (base → mysql → registry → docker/tests → démos).
