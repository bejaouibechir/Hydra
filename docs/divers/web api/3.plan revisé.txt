## 🎯 DÉCISIONS CRITIQUES DU CONSORTIUM

### **Architecture Policy-Driven (ChatGPT - Priorité #1)**

**Nouveau paradigme** : Séparer le connector en 2 couches

```
┌─────────────────────────────────────────────────────────────┐
│ COUCHE 1 : WebAPIConnector                                 │
│ Responsabilité : HTTP + Pagination + Parsing JSON          │
│ - Faire les requêtes                                        │
│ - Paginer les résultats                                     │
│ - Parser le JSON                                            │
└─────────────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────────┐
│ COUCHE 2 : Policies (plugins séparés)                      │
│ - RetryPolicy (retry + backoff + jitter)                   │
│ - RateLimitPolicy (respect Retry-After)                    │
│ - CircuitBreakerPolicy (open/half-open/close)              │
│ - TimeoutPolicy (connect/read timeouts)                    │
│ - AuthPolicy (API Key, Bearer, OAuth2 - Sprint 2)          │
└─────────────────────────────────────────────────────────────┘
```

**Avantage** : Extensibilité maximale sans toucher au core

---

### **Stratégie Arrays : EXPLODE par défaut (Grok - Priorité #3)**

**Décision finale** : 3 options seulement

```yaml
schema:
  fields:
    - name: prices
      path: "prices[*]"
      array_handling: explode  # ✅ DÉFAUT (long format)
      # Options : explode | flatten | keep_json
```

**Résultats** :

```python
# Input
{"id": 1, "prices": [10, 20, 30]}

# explode (DÉFAUT) → Long format (analytics-friendly)
[
  {"id": 1, "price": 10, "price_index": 0},
  {"id": 1, "price": 20, "price_index": 1},
  {"id": 1, "price": 30, "price_index": 2}
]

# flatten → Wide format
{"id": 1, "prices_0": 10, "prices_1": 20, "prices_2": 30}

# keep_json → String JSON
{"id": 1, "prices": "[10, 20, 30]"}
```

**Recursivité** : Limite à 3 niveaux max pour éviter explosion infinie

## 🏗️ ARCHITECTURE RÉVISÉE (Policy-Driven)

```
plugins/connectors/web_api/
├── __init__.py
├── connector.py              # WebAPIConnector (HTTP + pagination + parsing)
│
├── policies/                 # ✨ NOUVEAU (policy-driven)
│   ├── __init__.py
│   ├── retry_policy.py       # Retry + backoff + jitter
```

## 🎯 DSL FINAL VALIDÉ

```yaml
sources:
  github_issues:
    type: web_api
    connection:
      base_url: "https://api.github.com"
      headers:                                    # ✅ Sprint 1
        Authorization: "token ${SECRET:GH_TOKEN}"
        User-Agent: "Hydra/1.0"
        Accept: "application/vnd.github.v3+json"
    extract:
      endpoint: "/repos/octocat/Hello-World/issues"
      batch_size: 100
      
    schema:
      mode: manual                                # Sprint 1 (auto → Sprint 2)
      fields:
        # Simple
        - name: issue_id
          path: "id"
          type: integer
          
        # Nested
        - name: author_login
          path: "user.login"
          type: string
        
        # Array → Explode (défaut)
        - name: label_name
          path: "labels[*].name"
          type: string
          array_handling: explode                 # ✅ Défaut
        
        # Nested dans array
        - name: comment_text
          path: "comments[*].text"
          type: string
          array_handling: explode
          
        - name: reply_author
          path: "comments[*].replies[*].author"   # Recursif
          type: string
          array_handling: explode
          max_depth: 3                            # ✅ Protection
```
