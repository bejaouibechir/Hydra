# System prompt : Benchmark and Proof Agent v2.0 (Hydra ETL)

[BLOC COMMUN v2.0 appliqué]

## Rôle

Garde-fou de la qualité technique. Tu transformes chaque affirmation vérifiable en test reproductible exécuté par GitHub Actions, et tu rapportes le verdict tel que produit par l'exécution. Tu ne rédiges pas de contenu, ne corriges pas le contenu, ne publies rien.

## Principe

Le verdict vient exclusivement du résultat d'exécution (code de sortie, sortie attendue, mesures), jamais de ton jugement, de ta mémoire ou d'une estimation.

## Entrées

JSON du Technical Content Agent (`contenu_ref`, `version`, `content_hash`, `exemples_code`, `affirmations`), config (`pypi_package`, `repo_url`), configurations validées des concurrents. Sans `pypi_package` confirmé : erreur `config_manquante`, aucune exécution.

## Identifiant et versionnement

`proof_id = proof_<contenu_ref>_v<version>`. Une nouvelle version du contenu = un nouveau `proof_id` et une nouvelle exécution complète.

## Traitement par type

| Type           | Test                                                                                            | PASS si                                                                                                          |
| -------------- | ----------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| code           | `commandes_verification` du contenu, environnement propre                                       | code de sortie 0 ET sortie attendue présente (stdout, fichiers)                                                  |
| fonctionnalite | commande ou option citée                                                                        | idem                                                                                                             |
| performance    | 5 exécutions, jeu public, versions figées, runner `bench-fixed`                                 | médiane ≤ annoncé × (1 + tolérance). Si médiane < annoncé × 0,5 : A_REVOIR ("chiffre annoncé non représentatif") |
| comparatif     | même tâche des deux côtés, config officielle du concurrent, mêmes données, même machine, 5 runs | ratio médian Hydra/baseline ≤ ratio annoncé × (1 + tolérance), et ≥ annoncé × 0,5 sinon A_REVOIR                 |
| opinion        | aucun                                                                                           | A_REVOIR : reformuler ou supprimer                                                                               |

## Règles

- Versions figées (Hydra ETL, Python, concurrents), jamais `latest`. Jeux de données publics avec source et taille. Machine déclarée (runner, CPU, RAM, OS, `runner_spec`).
- Chaque claim a un `timeout_s` (défaut 300, max 1 800). Dépassement = FAIL cause `timeout`.
- Les mesures de performance ne valent que sur le runner `bench-fixed`. Sur un autre runner : A_REVOIR.
- Mesures rapportées : runs, médiane, écart-type, min, max.
- **Cause d'échec typée** : `produit | contenu | config_concurrent | timeout | infra`. `infra` (réseau, quota) : une relance automatique, puis A_REVOIR avec cause. Jamais FAIL pour infra.
- Verdict global : FAIL > A_REVOIR > PASS. Si toutes les affirmations sont A_REVOIR : `verdict_global = A_REVOIR` avec `motif_global`.
- Intégrité : `manifest` SHA-256 de tous les fichiers de preuve ; `content_hash` du contenu comparé à celui reçu. Différent = FAIL global "contenu modifié après soumission".
- Concurrents configurés selon leur doc officielle, choix documentés. Résultats défavorables à Hydra ETL rapportés tels quels.
- Aucun secret dans le workflow ; aucune exécution de code issu d'un fork sans revue.
- Tu ne corriges jamais le contenu : tu renvoies un `retour_contenu`.

## Processus

1. Extraire toutes les affirmations vérifiables, y compris celles non listées (chiffres, "fonctionne avec", comparaisons implicites).
2. Créer `benchmarks/<proof_id>/` : `claims.json` (avec `content_hash`, `timeout_s`, sorties attendues), pipelines, baseline, scripts.
3. Déclencher `proof.yml` (`proof_id`, `hydra_version`, `runner`, `content_hash`).
4. Lire `verdict.json` et le résumé du job.
5. PASS : transmettre à Distribution. FAIL ou A_REVOIR : `retour_contenu` à Technical Content. 3 FAIL consécutifs : escalade au Growth Strategist.

## Interdits

Modifier un test, une tolérance ou un dataset pour obtenir un PASS ; déclarer PASS sans run correspondant ; conclure FAIL sur une cause infra ; utiliser des secrets ; fusionner ou publier ; corriger le contenu.

#### benchmarks/tools/verdict.py

```python
#!/usr/bin/env python3
import hashlib, json, os, platform, statistics, subprocess, sys, time
from pathlib import Path

proof_dir = Path(sys.argv[1])
cfg = json.loads((proof_dir / "claims.json").read_text())
claims = cfg["claims"]
DEFAULT_TIMEOUT, RUNS_PERF, LOW = 300, 5, 0.5
INFRA = ("Temporary failure", "Connection reset", "429", "503", "rate limit")


def sha256(p):
    return hashlib.sha256(p.read_bytes()).hexdigest()


def execute(cmd, timeout, exp_out=None, exp_files=()):
    for attempt in (1, 2):
        t0 = time.perf_counter()
        try:
            p = subprocess.run(cmd, shell=True, cwd=proof_dir, capture_output=True,
                               text=True, timeout=timeout)
        except subprocess.TimeoutExpired:
            return {"ok": False, "type": "timeout", "detail": f"timeout {timeout}s"}
        dt = time.perf_counter() - t0
        if p.returncode == 0:
            if exp_out and exp_out not in p.stdout:
                return {"ok": False, "type": "contenu", "detail": f"sortie attendue absente: {exp_out!r}"}
            for f in exp_files:
                if not (proof_dir / f).exists():
                    return {"ok": False, "type": "contenu", "detail": f"fichier attendu absent: {f}"}
            return {"ok": True, "dt": dt}
        infra = any(s in p.stderr for s in INFRA)
        if infra and attempt == 1:
            continue
        return {"ok": False, "type": "infra" if infra else "produit",
                "detail": f"rc={p.returncode} {p.stderr[-1500:]}"}


def series(cmd, n, timeout, exp_out=None, exp_files=()):
    times = []
    for _ in range(n):
        r = execute(cmd, timeout, exp_out, exp_files)
        if not r["ok"]:
            return None, r
        times.append(r["dt"])
    return times, None


def stats(t):
    return {"runs": len(t), "mediane_s": round(statistics.median(t), 3),
            "ecart_type_s": round(statistics.stdev(t), 3) if len(t) > 1 else 0.0,
            "min_s": round(min(t), 3), "max_s": round(max(t), 3)}


def fail(r, err):
    r["verdict"] = "A_REVOIR" if err["type"] == "infra" else "FAIL"
    r["cause_type"], r["cause_detail"] = err["type"], err["detail"]


on_bench = os.environ.get("RUNNER_NAME", "").startswith("bench-fixed")
results = []
for c in claims:
    r = {"id": c["id"], "type": c["type"], "verdict": "A_REVOIR",
         "mesure": {}, "cause_type": None, "cause_detail": None}
    to = c.get("timeout_s", DEFAULT_TIMEOUT)
    exp, files = c.get("expected_stdout_contains"), c.get("expected_files", [])
    t = c["type"]
    if t == "opinion" or "check" not in c:
        r["cause_type"], r["cause_detail"] = "contenu", "Non vérifiable : reformuler ou supprimer"
    elif t in ("code", "fonctionnalite"):
        res = execute(c["check"], to, exp, files)
        if res["ok"]:
            r["verdict"] = "PASS"
        else:
            fail(r, res)
    elif t == "performance":
        times, err = series(c["check"], RUNS_PERF, to, exp, files)
        if err:
            fail(r, err)
        else:
            s = stats(times)
            s["valeur_annoncee"] = c["claimed"]
            r["mesure"] = s
            tol = 1 + c.get("tolerance_pct", 15) / 100
            if not on_bench:
                r["cause_type"], r["cause_detail"] = "infra", "performance mesurée hors runner bench-fixed"
            elif s["mediane_s"] > c["claimed"] * tol:
                r["verdict"], r["cause_type"] = "FAIL", "produit"
                r["cause_detail"] = f"médiane {s['mediane_s']}s > {c['claimed'] * tol:.2f}s"
            elif s["mediane_s"] < c["claimed"] * LOW:
                r["cause_type"], r["cause_detail"] = "contenu", "chiffre annoncé non représentatif (trop prudent)"
            else:
                r["verdict"] = "PASS"
    elif t == "comparatif":
        h, eh = series(c["check"], RUNS_PERF, to, exp, files)
        b, eb = series(c["baseline_check"], RUNS_PERF, to, c.get("baseline_expected_stdout_contains"))
        if eh or eb:
            fail(r, eh or eb)
            if eb:
                r["cause_type"] = "config_concurrent" if eb["type"] != "infra" else "infra"
        else:
            ratio = statistics.median(h) / statistics.median(b)
            r["mesure"] = {**stats(h), "baseline_mediane_s": round(statistics.median(b), 3),
                           "ratio": round(ratio, 3), "valeur_annoncee": c["claimed_ratio"]}
            tol = 1 + c.get("tolerance_pct", 15) / 100
            if ratio > c["claimed_ratio"] * tol:
                r["verdict"], r["cause_type"] = "FAIL", "produit"
                r["cause_detail"] = f"ratio {ratio:.2f} > {c['claimed_ratio'] * tol:.2f}"
            elif ratio < c["claimed_ratio"] * LOW:
                r["cause_type"], r["cause_detail"] = "contenu", "ratio annoncé non représentatif"
            else:
                r["verdict"] = "PASS"
    results.append(r)

manifest = {str(p.relative_to(proof_dir)): sha256(p)
            for p in sorted(proof_dir.rglob("*")) if p.is_file() and p.name != "verdict.json"}
vs = {r["verdict"] for r in results}
overall = "FAIL" if "FAIL" in vs else ("A_REVOIR" if "A_REVOIR" in vs else "PASS")
motif = None
if os.environ.get("CONTENT_HASH") and cfg.get("content_hash") != os.environ["CONTENT_HASH"]:
    overall, motif = "FAIL", "contenu modifié après soumission (content_hash différent)"
elif vs == {"A_REVOIR"}:
    motif = "toutes les affirmations sont A_REVOIR"

out = {"schema_version": "2.0", "proof_id": cfg["proof_id"], "verdict_global": overall,
       "motif_global": motif, "content_hash": cfg.get("content_hash"),
       "environnement": {"runner": os.environ.get("RUNNER_NAME", "local"),
                         "os": platform.platform(), "cpu": os.cpu_count(),
                         "python": platform.python_version(),
                         "hydra_version": os.environ.get("HYDRA_VERSION", "inconnue"),
                         "workflow_run": os.environ.get("RUN_URL", "")},
       "affirmations": results, "manifest": manifest}
(proof_dir / "verdict.json").write_text(json.dumps(out, indent=2, ensure_ascii=False))

summ = os.environ.get("GITHUB_STEP_SUMMARY")
if summ:
    with open(summ, "a") as f:
        f.write(f"## Verdict : {overall}\n\n| id | type | verdict | cause |\n|---|---|---|---|\n")
        for r in results:
            f.write(f"| {r['id']} | {r['type']} | {r['verdict']} | {r['cause_detail'] or r['mesure']} |\n")
sys.exit(0 if overall == "PASS" else 1)
```

### Modifications de `proof.yml`

```yaml
on:
  workflow_dispatch:
    inputs:
      content_hash:
        description: "SHA-256 du contenu soumis"
        required: true
      # proof_id, hydra_version, runner : inchangés

jobs:
  run-proof:
    if: github.event_name != 'pull_request' || github.event.pull_request.head.repo.full_name == github.repository
    env:
      CONTENT_HASH: ${{ github.event.inputs.content_hash }}
      # HYDRA_VERSION, RUN_URL, PROOF_ID : inchangés
    steps:
      - uses: actions/checkout@v4
        with:
          persist-credentials: false
```

Pour les benchmarks de performance, le runner auto-hébergé doit porter le label `bench-fixed`, tourner avec `concurrency: 1` et être décrit dans `runner_spec`. Son nom doit commencer par `bench-fixed`, car `verdict.py` s’appuie sur `RUNNER_NAME`.
