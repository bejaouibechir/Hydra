# Validate a job over HTTP

`curl -s -X POST http://127.0.0.1:5678/api/jobs/validate -H "Content-Type: application/json" -d '{"path": "apijob"}' | /opt/hydra/bin/python -m json.tool`{{exec}}

```json
{
    "returncode": 0,
    "stdout": "...DSL valid — no errors detected.\n",
    "stderr": "",
    "success": true
}
```

`stdout` is not a summary generated by the API — it is the literal text `hdrctl validate apijob` would print in a terminal, captured from the subprocess and handed back as a JSON string. `returncode` is the process's real exit code.

When you are done, click **Check** to continue.
